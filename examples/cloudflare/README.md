# Плагин Cloudflare DNS

> **WARNING:** пример использует сторонний сервис (Cloudflare) — его доступность и условия не гарантируются.

Плагин хаба nkt для зон, которые живут у Cloudflare: всё, что умеет
DNS-плагин хаба, — без своего сервера имён.

- **Записи из хаба:** таблица, добавить, удалить, «задать» ровно эти
  значения; вся зона текстом `ИМЯ TTL ТИП ЗНАЧЕНИЕ [proxied]` в окне
  правки с диффом и историей. `proxied` — оранжевое облако Cloudflare
  (только A, AAAA, CNAME). NS вершины назначает Cloudflare — в тексте он
  комментарием и не правится.
- **Делегирование:** какие NS назначил Cloudflare и что видят публичные
  резолверы.
- **Сценарии:** `cf set|add|rm|check …`; **MCP:** `cloudflare_*`.
- **Для хаба** (`provides: dns`): имена маршрутов Traffic Fly, домены
  сайтов (`site.dns`), автоимена хостов. Прокси для них выключен.
  Failover у Cloudflare — только платный Load Balancing: при нескольких
  шлюзах ставятся все адреса, по кругу.

Зоны заводятся в панели Cloudflare — плагин их не создаёт и не удаляет.

## Токен

dash.cloudflare.com → **My Profile → API Tokens → Create Token** →
шаблон **Edit zone DNS** → Zone Resources: **Include → Specific zone** —
только нужные зоны. Токен с правом на весь аккаунт не нужен.

## Поставить

**Без Docker** (рекомендуется): «О системе» → «Плагины» → **«Установить на
хост»** → Cloudflare DNS → машина хаба или любой хост с интернетом →
токен. Хаб поставит службу `nkt-plugin-cloudflare` (порт 9190 на
127.0.0.1) и подключит её. Второй аккаунт — ещё раз с другим именем
(`cloudflare2`).

**Контейнером:** конвейер из [`pipeline.yaml`](pipeline.yaml), затем «О
системе» → «Плагины» → «Подключить» → «С конвейера».
