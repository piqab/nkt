# Плагин connector: устройства по профилям

Устройства без агента nkt — **без своего кода**: тип устройства описывается
профилем (JSON), а плагин подключается, читает и разбирает ответы сам.
Каждый профиль — тип в «Хосты» → «Добавить устройство».

| Профиль | Связь | Что |
|---|---|---|
| `linux-ssh` | SSH | старые и закрытые Linux, куда нельзя поставить nkt |
| `macos` | SSH | macOS: службы launchd, brew, брандмауэр, FileVault, SIP, обновления |
| `freebsd` | SSH | FreeBSD: службы, pkg и `pkg audit`, `freebsd-update`, rc.conf, pf.conf |
| `openwrt` | SSH | OpenWrt: Wi-Fi (сети, шифрование, клиенты), DHCP, зоны firewall, проброс портов, пакеты и обновления (opkg, apk), находки (wan, открытая сеть, WEP, WPA1, TKIP, WPS…), `uci export` с диффом — ключи под `***` |
| `keenetic` | HTTP (RCI) | Keenetic: интерфейсы, устройства в сети, running-config, команды CLI |
| `snmp-printer` | SNMP v2c | принтер: расходники (находка — меньше 10 %), счётчик страниц |
| `snmp-switch` | SNMP v2c | коммутатор: порты, соседи по LLDP, трафик портов |
| `snmp-ups` | SNMP v2c | ИБП с сетевой картой (UPS-MIB, APC PowerNet): питание, заряд, время от батареи, нагрузка, напряжение, самотест; находки — от батареи, разряд, замена батареи, перегрузка, температура |
| `nut-ups` | NUT (3493) | любой ИБП на сервере NUT: все переменные, те же находки, быстрый самотест |
| `onvif-camera` | ONVIF | IP-камеры и регистраторы: модель, прошивка, потоки RTSP, часы (находка — расхождение больше минуты), диски регистраторов Hikvision и Dahua, перезагрузка |

Свои профили — раздел плагина «Профили»: «Новый профиль» (на основе
встроенного) и «Править» — окно с диффом и историей версий в хабе.
Свой профиль с именем встроенного заменяет его. Формат — справка
«[Хосты плагинов](https://piqab.github.io/nkt/guide/hub-plugin-hosts)».

## Поставить

«О системе» → «Плагины» → **«Установить на хост»** → Connector — на машину
хаба или любой хост, откуда видны устройства. Для SSH-профилей на этом
хосте нужен клиент OpenSSH (`ssh`, `ssh-keyscan`). Служба
`nkt-plugin-connector`, 127.0.0.1:9230; свои профили — в её каталоге
данных (`/var/lib/nkt-plugin-connector`).

## Безопасность

- Учётки устройств хранит хаб (зашифрованными) и передаёт в каждом
  вызове; плагин их не хранит и не пишет в журнал.
- SSH: ключ хоста запоминается при «Проверить» и сверяется при каждом
  подключении (`StrictHostKeyChecking=yes` по запомненному); пароль идёт
  через `SSH_ASKPASS`, не в командной строке; закрытый ключ — во временном
  файле 0600, который удаляется после вызова.
- Аргументы действий из формы — только латиница, цифры и `._@/:+-`, в
  команду подставляются в кавычках (`shlex.quote`).
- SNMP — только чтение (v2c); community `public` — находка.
- ONVIF: пароль уходит дайджестом WS-Security, для API регистратора —
  HTTP digest; открытым текстом пароль не передаётся. NUT — без шифрования
  (как у самого upsd): держите сервер NUT в доверенной сети.
- OpenWrt: ключи Wi-Fi, WireGuard и прочие секреты в `uci export`
  заменяются на `***` до того, как конфигурация попадёт в хаб.

## Проверка

`python3 -I deploy/test_plugin.py` — плагин против поддельных `ssh` и
`ssh-keyscan`, поддельного Keenetic и SNMP-агента; его же запускает
`go test ./examples`.
