# Gitea + PostgreSQL — веб через сайт, SSH наружу

[Gitea](https://gitea.com) — git-сервер. У проекта нет своего
compose-файла для выкладки, поэтому он здесь:
[`deploy/docker-compose.yml`](deploy/docker-compose.yml) — Gitea 28.0 и
PostgreSQL 17, пароль и адреса — из `.env`.

**Два порта — два пути наружу:**
- веб (3000) — через сайт: блок `site:` публикует его на 127.0.0.1 и
  выпускает сертификат;
- SSH для `git clone git@…` (2222 → 22 в контейнере) — напрямую:
  `ports: gitea: ["0.0.0.0:2222:22"]` в конвейере. Без этой строки `bind`
  по умолчанию оставил бы SSH только на 127.0.0.1. **Откройте 2222/tcp в
  файрволе хоста** (сайт открывает только 80/443).

«Примеры» → «Gitea + PostgreSQL», хост, имя в `site:`; `.env` — по
шаблону в `pipeline.yaml`. Первый вход — страница установки с
заполненными из `.env` настройками базы; заведите администратора.

Проверено: выкладка на docker 29 за ~15 секунд, оба сервиса healthy, `/api/healthz` — `pass`, SSH опубликован на `0.0.0.0:2222`.
