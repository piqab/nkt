# Плагин Home Assistant

Home Assistant как хост nkt — одно устройство в «Хостах», без дополнений
на стороне Home Assistant: всё через его REST API.

- **Состав:** версия, тип установки, области с числом сущностей,
  интеграции, автоматизации (включены или нет), число устройств и
  сущностей, доступные обновления, недоступные сущности, батареи.
- **Находки:** сущности недоступны дольше 30 минут; батарея ниже 20 %;
  доступно обновление ядра, ОС, дополнения или прошивки (сущности
  `update.*`); резервной копии нет больше 7 дней (если включена интеграция
  резервных копий).
- **Конфигурация** с диффом: какие сущности (с именами), автоматизации и
  интеграции есть — без состояний, так что дифф показывает, что добавили,
  убрали или переименовали.
- **Действия:** перезапуск Home Assistant, установка обновления
  (`update.*`), запуск сценария (`script.*`), запуск автоматизации
  (`automation.*`), перечитать автоматизации.
- **Команды** — вызов службы Home Assistant: на странице устройства, в
  сценариях хаба (`on дом run "light.turn_off {\"entity_id\": \"light.hall\"}"`)
  и MCP (`device_exec`). Формат — `домен.служба` и, если нужно, данные
  JSON-объектом.

## Home Assistant

Профиль пользователя → «Безопасность» → **«Долгоживущие токены доступа»** →
«Создать токен». Для действий и вызова служб нужен пользователь-
администратор.

## Поставить

«О системе» → «Плагины» → «Каталог» → Home Assistant → **«Установить на
хост»** — машина хаба или любой хост, откуда виден Home Assistant (порт
8123). Служба `nkt-plugin-home-assistant`, 127.0.0.1:9260. Затем «Хосты» →
**«Добавить устройство»** → «Home Assistant» → адрес, токен, связь (HTTP
или HTTPS с запомненным отпечатком) → «Проверить» → «Добавить».

Токен хранит хаб (зашифрованным) и передаёт в каждом вызове; плагин его
не хранит и не пишет в журнал. Имена сущностей в действиях проверяются
(`домен.имя`, латиница, цифры, `_`), данные службы — только объект JSON.

## Проверка

`python3 -I deploy/test_plugin.py` — плагин против поддельного REST API
Home Assistant; его же запускает `go test ./examples` и CI перед сборкой
каталога.
