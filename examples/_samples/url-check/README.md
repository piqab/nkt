# Проверка адресов — пример своего плагина

Пример плагина, который загружают в хаб как **свой** («Плагины» → «Каталог»
→ «Загрузить свой плагин»), а не берут из каталога. Написан по
[руководству для агентов](../../AGENTS.md) из [заготовки](../../_template).

- **Адреса** — из настройки `URL_CHECK_TARGETS` (через запятую): код
  ответа, время, сколько дней до конца сертификата.
- **Находки:** не отвечает или 5xx; ответ дольше порога
  (`URL_CHECK_SLOW_MS`, по умолчанию 2000 мс); сертификат истекает меньше
  чем через 14 дней или истёк.
- **Команда сценария** `urlcheck АДРЕС` — проверить один адрес; не
  прошёл — шаг сценария падает (удобно после выкладки).
- **MCP:** `url-check_status`, `url-check_findings`, `url-check_check`.

Безопасность: адреса — только `http://` и `https://`, без логина в адресе;
ответ читается не дальше 64 КБ, таймаут 10 с; сертификаты проверяются
(свой УЦ — `URL_CHECK_CA_FILE`). Проверка произвольного адреса (`check`,
`urlcheck`) — не для токенов чтения: это запрос с хоста плагина куда
угодно.

## Загрузить в хаб

1. Архив: готовый — `https://piqab.github.io/nkt/samples/url-check.tar.gz`
   (ссылка «Скачать пример» в окне загрузки), или из репозитория:
   `tar czf url-check.tar.gz -C examples/_samples url-check`.
2. «О системе» → «Плагины» → «Каталог» → **«Загрузить свой плагин»** →
   архив → посмотрите код → «Код просмотрен» → «Сохранить».
3. В каталоге — «Проверка адресов» с меткой «свой» → «Установить на хост»
   → адреса в форме → задание.

Проверка: `python3 -I deploy/test_plugin.py`,
`go run ./cmd/nkt-catalog lint -dir examples/_samples/url-check`.
