# Плагин MikroTik (RouterOS 7)

Роутеры и коммутаторы MikroTik как хосты nkt — эталонный плагин для
[хостов плагинов](https://piqab.github.io/nkt/guide/hub-plugin-hosts):
устройство без агента nkt, которое читает и которым управляет плагин.

- **Состав:** модель, версия, прошивка, процессор и память, интерфейсы и
  адреса, порты служб и откуда они открыты, соседи (MNDP/LLDP), маршруты,
  firewall, выданные DHCP-адреса, пакеты, пользователи.
- **Метрики** (раз в минуту — в «Мониторинг» хаба): процессор, память,
  диск, температура, скорость интерфейсов.
- **Находки:** доступно обновление RouterOS или прошивки; telnet; службы
  (www, ftp, api) открыты для всех адресов; пользователь `admin`; нет
  запрета входящих в firewall; связь без шифрования.
- **Конфигурация** `/export terse` — хаб хранит версии и показывает дифф:
  что поменяли на роутере, видно, кто бы ни менял.
- **Действия:** перезагрузка, обновление RouterOS, прошивка RouterBOARD,
  резервная копия на роутере.
- **Команды** RouterOS: на странице устройства, в сценариях
  (`on роутер run "/ip dns cache flush"`) и в MCP (`device_exec`).

## Роутер

RouterOS 7 (REST API есть с 7.1; RouterOS 6 не поддерживается).

```
/ip service enable www-ssl
/ip service set www-ssl address=<адрес хоста с плагином>/32
/user add name=nkt group=full password=<пароль>
```

Группа `read` хватит, чтобы смотреть (состав, метрики, находки,
конфигурация); для действий и команд нужна `full`. У роутера свой
сертификат: его отпечаток nkt запоминает при «Проверить» и сверяет при
каждом подключении — подмену не пропустит.

## Поставить и подключить

1. «О системе» → «Плагины» → **«Установить на хост»** → MikroTik → машина
   хаба или любой хост, откуда видны роутеры. Служба
   `nkt-plugin-mikrotik`, 127.0.0.1:9220, без Docker.
2. «Хосты» → **«Добавить устройство»** → тип «MikroTik RouterOS» →
   адрес, пользователь, пароль → «Проверить» → «Добавить».

Учётки роутеров хранит хаб (зашифрованными, как SSH-ключи хостов) и
передаёт плагину в каждом вызове; плагин их не хранит и не пишет в журнал.

## Проверка

`python3 -I deploy/test_plugin.py` — плагин против поддельного REST
RouterOS 7 по HTTPS (без роутера); его же запускает `go test ./examples`.
