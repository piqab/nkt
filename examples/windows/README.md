# Плагин Windows (OpenSSH + PowerShell)

Windows-серверы и рабочие станции как хосты nkt — без агента и без WinRM,
через встроенный OpenSSH Server и PowerShell 5.1+.

- **Состав:** ОС и сборка, процессор, память, диски, адаптеры и адреса,
  службы, программы, обновления (KB), порты и процессы на них,
  пользователи и администраторы, роли сервера.
- **Метрики** (раз в минуту — в «Мониторинг» хаба): процессор, память,
  системный диск, трафик адаптеров.
- **Находки:** ожидают обновления; нужна перезагрузка; Defender или защита в
  реальном времени выключены, старые базы; брандмауэр выключен в профиле;
  RDP без NLA; SMBv1; включён «Гость»; BitLocker выключен; диск заполнен;
  ошибки журналов System и Application за сутки.
- **Конфигурация** с диффом: разрешающие входящие правила брандмауэра,
  типы запуска служб, локальные администраторы.
- **Действия:** перезагрузка; служба — запустить, остановить,
  перезапустить; установить обновления (в фоне, задачей планировщика
  `NktWindowsUpdate`, журнал — `C:\ProgramData\nkt\updates.log`); `winget
  upgrade`.
- **Команды PowerShell:** на странице устройства, в сценариях
  (`on win1 run "Get-Process | Sort CPU -desc | Select -First 5"`) и MCP
  (`device_exec`).

## Windows

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service sshd -StartupType Automatic
```

Пользователь — администратор (часть находок и все действия требуют прав).
Вход по паролю или ключу: для администраторов Windows ключи лежат в
`C:\ProgramData\ssh\administrators_authorized_keys`.

## Поставить

«О системе» → «Плагины» → **«Установить на хост»** → Windows — машина хаба
или хост, откуда видны Windows-машины (нужен клиент OpenSSH). Затем
«Хосты» → **«Добавить устройство»** → «Windows» → адрес, пользователь,
пароль или ключ → «Проверить» → «Добавить».

## Как это устроено

Сценарий PowerShell уходит в стандартный ввод SSH, а в командной строке —
только короткий загрузчик `powershell -EncodedCommand …` (у `cmd.exe` предел
8191 знак); ответ — JSON в UTF-8. Ключ хоста запоминается при «Проверить» и
сверяется; пароль идёт через `SSH_ASKPASS`, не в командной строке; учётки
хранит хаб.
