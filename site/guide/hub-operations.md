# Оповещения, задания, экспорт, обновления

## Оповещения

![Оповещения](/screens/ru/hub-alerts.png)

Хаб сам замечает переходы: хост **недоступен** / **снова отвечает**,
появились **серьёзные проблемы** / **исправлены**, **задание не
выполнено**. Журнал оповещений с настройкой, что записывать и о чём
уведомлять; короткие эпизоды («не отвечает» → «снова отвечает» через
пару минут) сворачиваются в одну строку «был недоступен N мин».

Переключатель **«Уведомлять о проблемах»** включает уведомления браузера
— они приходят в любом разделе хаба, пока вкладка открыта. Счётчик
непрочитанных — у пункта меню.

## Задания хаба

Установка nkt на хост, обновление, создание машины, применение профиля
группе, сценарий — всё это задания хаба с журналом в реальном времени;
задание, прерванное перезапуском хаба, продолжается.

## Экспорт и импорт

«Экспорт» в списке хостов сохраняет всё, что хаб знает и что долго
заводить заново: хосты с SSH- и admin-секретами, группы, машины с
родителями, профили с историей, шаблоны машин, сценарии, настройки. Файл
шифруется паролем — его же спросит «импорт» на новом хабе.
`nkt hub import` делает то же из командной строки.

## О системе

![О системе](/screens/ru/hub-about.png)

- Версия хаба, проверка релизов GitHub, **обновить до последней** — хаб
  скачивает бинарник, проверяет контрольную сумму и перезапускается;
  **откат** на предыдущую версию, если что-то пошло не так. Описание новой
  версии показывается до установки.
- Хосты с версией, отличной от хаба, приводятся к версии хаба при
  открытии; «обновить всё» в списке хостов — для отставших.
- **База уязвимостей** trivy — общая для всех хостов: обновление по
  расписанию и по кнопке, хосты берут её с хаба, а не качают сами.
