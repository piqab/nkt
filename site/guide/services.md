# Сервисы

![Сервисы](/screens/ru/services.png)

Список юнитов systemd с состоянием, автозапуском, описанием и портами,
которые слушает каждый.

- **Действия**: одна кнопка питания по состоянию (работает — «остановить»,
  остановлен — «запустить»), перезапустить, перечитать (`reload`), одна
  кнопка автозапуска по состоянию, журнал юнита.
- **Проверка конфигурации перед действием**: `nginx -t`, `haproxy -c`,
  `caddy validate` — сломанный конфиг не уронит сервис перезапуском.
- **Другие сервисы** — процессы, запущенные вручную или из контейнера, с
  их сокетами и отметкой, открыт ли порт наружу; завершение по
  SIGTERM/SIGKILL.
- **Установка отсутствующего сервиса** пакетом с живым журналом apt.
- **Проверка порта**: TCP, HTTP/HTTPS, TLS-рукопожатие, произвольный
  `curl` — с телом ответа, заголовками, отрисовкой полученной страницы и
  скачиванием ответа. То же доступно из «Сетевых интерфейсов» у портов,
  открытых на `0.0.0.0`.
