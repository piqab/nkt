# Пакеты, диски и файлы, оборудование, система

## Пакеты

- Поиск пакетов apt с ранжированием по совпадению, установка нескольких
  одной транзакцией; описание пакета — по наведению.
- Установленные пакеты — сеткой с поиском и удалением.
- Доступные обновления и `apt-get upgrade` в живом окне терминала —
  намеренно без `-y`, с подтверждением.
- Пакеты snap и flatpak: список, обновление, удаление.

## Диски и файлы

- Файловые системы с занятостью (псевдо-ФС скрыты), подкачка, физические
  диски и разделы.
- **Что занимает место**: размеры подкаталогов по клику, уровень за
  уровнем.
- **Файлы** — проводник по разрешённым корням, из которых показываются
  только существующие (`/home`, `/srv`, `/opt`, `/tmp`,
  `/var/www`; список настраивается `NKT_FILES_ROOTS`): папки,
  переименование, удаление, скачивание; загрузка файлов и целых папок
  через диалог или перетаскиванием с общим прогрессом (галочка **«без
  скрытых»**, включена по умолчанию, не грузит скрытое — `.git`, `.env`
  — и то, что перечислено в `.gitignore` загружаемой папки; неудачный
  файл повторяется до трёх раз, оставшиеся — кнопкой «повторить
  неудачные»); распаковка
  zip/tar на месте; `git clone` заданием, в том числе приватных
  репозиториев (токен по HTTPS или deploy-ключ хоста по SSH).
- **Загрузка с планом.** Перед записью — окно «Что изменится»: какие
  файлы новые, какие заменят существующие (у текстовых — дифф «на хосте →
  загружаемый»), какие совпадают (их не загружают), какие защищены. У
  каждого файла — галочка. Загрузка ничего не удаляет на хосте.
- **Защищённые файлы папки** — шаблоны, которые загрузка по умолчанию не
  перезаписывает: `.env`, `.env.*`, `*.local.*`, `local_settings.*`,
  `wp-config.php`, `config.local.*`, каталоги `uploads/`, `storage/`,
  `media/`, `data/`. Список правится кнопкой «Защищённые» (с диффом и
  историей); перезаписать защищённый файл можно только явной галочкой в
  плане.
- **История загрузок.** Каждая загрузка — запись: кто, когда, куда,
  комментарий, какие файлы добавлены и заменены. Прежние версии
  заменённых файлов сохраняются; **«Откатить»** заданием возвращает их и
  убирает добавленное (файлы, изменённые после загрузки, не трогаются).
  У любого файла — «История версий» с диффом и откатом.
- **Хранилище истории** — занятость и лимиты: 200 МБ больших файлов на
  загрузку (текстовые хранятся всегда), 1 ГБ всего, 30 дней; сверх —
  вытесняется самое старое. Версии удаляются вручную: по одной, всю
  историю файла, загрузку целиком, всё старше выбранного срока. С 80%
  заполнения — находка в «Проблемах» и оповещение хаба.
- **Правка текстовых файлов — как в «Конфигурациях»**: номера строк,
  комментарий к правке, дифф «на диске → черновик» перед записью, защита
  от затирания чужой правки и вкладка **«История версий»** — кто, когда
  и зачем менял, дифф любой версии с текущим файлом, откат (тоже
  версией). Если файл — конфигурация известного сервиса (скажем,
  compose-файл в `/srv`), запись идёт с проверкой сервисом и откатом при
  ошибке, а история общая с «Конфигурациями».

## Оборудование

Машина, процессор, память, батареи, температуры (lm-sensors), PCI- и
USB-устройства.

## Системные настройки

- Имя машины, часовой пояс (с поиском), NTP, состояние автоматических
  обновлений безопасности.
- **Локали**: все известные системе с поиском, генерация выбранных,
  назначение основной.
- **Синхронизация времени**: какая служба стоит (systemd-timesyncd,
  chrony, ntpsec), с кем сверяется, stratum и расхождение; выбор
  серверов NTP; «синхронизировать сейчас»; установка службы, если её нет.
- NetworkManager: соединения, устройства, Wi-Fi-сети, подключение с
  паролем.

## Терминал

Полноценная оболочка на хосте в браузере (`NKT_TERMINAL_ENABLED=true`, по
умолчанию выключен — это прямой доступ к shell). tmux-сессии переживают
закрытие вкладки; открепление в отдельное окно; панель: копирование,
очистка, размер шрифта, поиск. tmux и dbus-помощники ставятся кнопкой,
если их нет.
