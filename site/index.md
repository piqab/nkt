features:
  - icon: 🔎
    title: Находит проблемы, а не только показывает
    details: Разбирает nginx, haproxy, caddy, docker compose, firewall и сертификаты, сверяет с живым состоянием хоста и объясняет каждую находку — файл, строка, что сделать.
  - icon: 🧩
    title: Всё на одном экране
    details: Сервисы, контейнеры Docker/Podman/LXD, машины libvirt с экраном VNC/SPICE в браузере, бэкапы и снимки, пакеты, диски, файлы, интерфейсы, оборудование, системные настройки — с действиями, а не только списками; долгие операции — фоновыми заданиями.
  - icon: 📝
    title: Конфиги с историей и проверкой
    details: Редактор с проверкой самим сервисом перед записью, версии, diff, откат, блочный редактор nginx/haproxy, защита sshd от «отрезать себе доступ».
  - icon: 🔐
    title: Сертификаты целиком
    details: Все сертификаты из конфигов и /etc/letsencrypt, сверка с TLS-сокетом, автопродление, выпуск Let's Encrypt, PEM для haproxy, самоподписанные.
  - icon: 🛡️
    title: Firewall, уязвимости, вредоносное
    details: ufw и firewalld с защитой порта 22; CVE в пакетах ОС хоста, внутри гостей LXD и libvirt и в образах через trivy; майнеры и признаки взлома без сторонних программ, ClamAV с карантином.
  - icon: 📈
    title: Наблюдение
    details: Доступность слушателей, портов контейнеров и машин по расписанию, тепловая карта простоев, нагрузка контейнеров и машин, живые логи, терминал и btop в браузере.
  - icon: 🖧
    title: Хаб — много хостов
    details: Хосты по SSH, группы, оповещения, задания, профили желаемого состояния, виртуальные машины из хаба, сценарии развёртывания, экспорт и импорт всего.
  - icon: 🌍
    title: Два языка, три темы
    details: Интерфейс и сообщения сервера на русском и английском, светлая, тёмная и системная темы, терминальный интерфейс и JSON API ко всему.
  - icon: 🔒
    title: Безопасно по умолчанию
    details: Один бинарник без зависимостей, systemd-песочница, argon2id, роли, режим «только чтение», журнал всех действий, слушает только localhost.
